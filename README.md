# 🚀 SalesCon   
SalesCon is a centralized digital platform designed to streamline food vendor management for campus events at Universiti Sains Malaysia (USM). It enables vendors to register, book event slots, manage payments, and comply with event regulations—all in one place.

# 🧩 Features
### 🎪 For Vendors:
Vendor Registration & Login

Browse Upcoming Events

Apply for Slot Rentals

Online Payment Integration

View Booking History

### 🧑‍💼 For Event Organizers:
Dashboard with Vendor & Event Analytics

Manage Vendor Applications

View Payment Statuses

Approve or Reject Slot Requests

Publish Event Reports

# 🌱 SDG Alignment
SalesCon supports Sustainable Development Goal (SDG) 8: Decent Work and Economic Growth by promoting sustainable, organized, and accessible economic opportunities for local food vendors.

# 🛠️ Tech Stack
Frontend: HTML, CSS, JavaScript

Backend: Flask (Python)

Database: SQLite / MySQL (based on implementation)

AI Integration: Event analytics, slot prediction, or chatbot (optional enhancement)
